1. **老玩家存档接管 / Legacy City Stewardship【最高优先级】**：这已经比 0→100K 更像最终产品。Mayor 加载任意成熟城市后，先诊断财政、交通、三网、服务、就业、住房、污染、垃圾、死亡、废弃、外连等，再决定修复/维持/扩张；不能因为某一区卡住让全城停转；不能为了优化随便毁掉玩家已有设计。最后验收不再只是“人口涨”，而是“坏城能救、好城不搞坏、能长期代管”。

2. **全局 Anti-Stall / Liveness Contract【必须】**：任何 `WAIT/FAIL/NO_SITE/REPLAN` 都必须有原因、等待条件、最长等待窗口和升级路径；同一失败指纹不能无限重复；连续无 objective progress 必须触发换策略/换区域/放宽 soft preference/明确 blocked。这个不是新 Brain，而是保证 **Mayor 可以失败，但不能悄悄死机两小时**。

3. **精确 Hands + 通用过滤器/Selector【还没闭合】**：现在缺的不是再造 Planner，而是“精确选谁”。最终需要按类型、区域、状态、关系、作者/来源、例外、保护条件选中对象，再 `OBSERVE → SELECT → ACT → VERIFY → SCOPE_SAFETY`。包括精确拆除、清 zoning、道路升级、替换服务设施、局部修复、只处理问题对象等。没有这个，老玩家存档改善很危险。

4. **成熟城市交通治理【现在明显没闭合】**：拥堵读回、瓶颈定位、路口改造、道路升级、公共交通、停车/步行/自行车、货运、外部连接等。100K 可以靠粗暴扩张绕过去，但“接管别人老城”绕不过去。尤其要从“看到堵车图标”升级成真实交通梯度/路径/瓶颈诊断。

5. **完整城市问题处理 / Remediation【部分】**：电、水、污水已经走得比较深，但垃圾、火灾、倒塌、废弃、救护车/灵车、租金、高技能劳动力、服务满载、污染、商业问题等还没有全部形成 `观察→诊断→动作→读回` 闭环。最终产品应该能救“烂档”，而不只是新建。

6. **财政恢复与坏档救援【需要正式产品化】**：负现金流、贷款高企、服务费爆炸、地块维护费拖垮、错误 zoning/设施过量时，Mayor 要能进入内部恢复状态，削减无效支出、暂停扩张、修复税基和岗位，再恢复正常自治。玩家不需要自己知道当前是 `FINANCIAL_RECOVERY`；如果你坚持单一模式，这些 Profile 最好退成 Mayor 内部状态。

7. **铁路 / 外部连接 / 货运 / Transit 能力【当前大量缺原语】**：这是 100K speedrun 和成熟城市都重要的一块。Passenger rail、多个 outside connection、线路/站点、货运连接、公共交通容量等，都应该最终变成真正可执行能力。当前“策略知道铁路重要但手脚没有”的情况最终不能留在产品里。

8. **道路、桥、隧道、地形的完整工程能力【部分】**：普通道路已经很强，但最终还要可靠区分桥/隧道/高架/坡度/跨河、批量跨越、道路升级和既有路网改造，而不是只会往空地新建。老档里尤其重要。

9. **Semantic Compiler ↔ Hands Capability Map【必须接上】**：Compiler 本身已经证明 typed MayorIntent 可以确定性求值，但这不代表本地真能执行。最终每个 Intent 必须落到 `CLOSED / PARTIAL / UNSUPPORTED` 的真实能力映射，不能向玩家承诺“我能做到”，结果下面根本没有手。自然语言与本地执行能力是两层，冻结规范已经明确分开。AI_MAYOR_SEMANTIC_COMPILER_V1_F…

10. **玩家自然语言输入器 / Semantic Frontend【核心尚未完成】**：玩家最终应该直接说“把东边堵车解决掉，但别拆老城区”“帮我把这座亏损城市救回来”“人口稳定在 12 万左右”。外部 AI 只负责自然语言 → `MayorIntent`，不能输出坐标、施工顺序、prefab、税率动作，更不能成为第二个 Mayor。Compiler 已经做好了，真正缺的是 **自然语言 fidelity 验证 + 正式接线**。当前文件明确说自然语言前端仍未验证。AI_MAYOR_SEMANTIC_COMPILER_V1_F…

11. **免费核心 + 免费外部 AI 层【你特别强调的】**：最终基础产品应该保持 **本地 Mayor 免费可运行、无需 API 也能自治**；旧架构资料本来就把 Local Mayor 定义为 free deterministic expert autopilot，而云 AI 只承担高级布局/风格/长期策略等低频任务。粘贴的文本 (1)(20260928-053322) 外部 AI 最适合只用在两处：① 玩家语言 → MayorIntent；② 少量真正需要开放语义的风格/复杂意图。断网/API 挂了，Mayor 仍然继续自治，不能停城。
